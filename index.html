Como usar em campo
1. Instale na tela inicial. Toque em Instalar na tela inicial aqui em cima, ou use o menu ⋮ do Chrome → Instalar aplicativo.

2. Abra uma vez com internet. A partir daí funciona offline para sempre. Verificando o modo offline…

3. Coordenada. O botão Capturar GPS é o caminho normal. Se a câmera do Android estiver com Salvar localização ligado, a foto também traz o ponto. E dá para colar o par copiado de outro app.

4. Os dados ficam no aparelho. Nada é enviado para servidor algum. Exporte a planilha ao fim de cada dia e guarde também o backup .json.
